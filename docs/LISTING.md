# App Directory listing copy

Written to Zapier's naming and description rules: the app name is the plain brand name (no "Zapier", "API", "Integration" or "for"), descriptions are plain and do not repeat the app name needlessly. Character counts are checked below.

- **App name:** ReadAloud
- **Category:** Content & Files (alternative: Developer Tools)
- **Short description (max 140 characters):**
  Turn text into natural-sounding speech and get an audio file you can send, store or attach in any Zap.
- **Intro / long description:**
  ReadAloud converts text into spoken audio. Add the Convert Text to Speech action to any Zap to generate an MP3, WAV or Opus file from a new blog post, support reply, form entry or any other text, then send it to Slack, Google Drive, email or anywhere else that accepts files. Choose a voice, set the speaking speed, and name the file. You need a ReadAloud account and an API key from readaloudai.org.
- **Action label and description:** Convert Text to Speech: Converts text to spoken audio and returns an audio file you can use in later steps.
- **Auth help text:** Create an API key in your account at readaloudai.org, then paste it here.
- **Website:** https://readaloudai.org
- **Support contact:** support@readaloudai.org
- **Logo:** `logo.png` (512x512 PNG, transparent corners, original neutral design)
- **Suggested starter Zap ideas:** read new RSS items aloud and save to Drive; turn form responses into audio replies; create an audio version of a new Notion page.
